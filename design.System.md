# Design System do Projeto XYZ

## 1. Introdução
Esta é uma página de autenticação simples e minimalista

## 2. Fundações
- Paleta de Cores
  --text: #060704;
  --background: #f8faf3;
  --primary: #a5be4d;
  --secondary: #cfdf94;
  --accent: #c0da63;

- Tipografia
  - Titulos:     Inter (via Google Fonts)
  - Texto normal: Sans-Sering


- Espaçamento
  - Grande ( 8 ou 16px)

## 3. Componentes
 -Botões:
    - Todos os botões vão:
     -Ter uma sombra pequena na parte inferior
     - Terão arrendondamento de 4px
     -Terão fontes negrito
     - Seguirão o espaçamento definido na fundação.
    - Variações:
      - Primario: seguirão a paleta a risca.
      - Secundario: terá o valor invertido do fundo/texto

    - Campo de texto (input):
    - Todos os inputs vão:
      - terão arrendondamento de 4px
      - seguirão espaçamento de finido na fundação

## 4. Guia de uso

- No CSS sempre usar variáveis para cores e elementos da fundação ao inves de espalhar pelo código.
